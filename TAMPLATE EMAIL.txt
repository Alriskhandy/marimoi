
### ✅ 2. Jalankan Permanen dengan Supervisor (disarankan)

1. **Install Supervisor**

   ```bash
   sudo apt update
   sudo apt install supervisor -y
   ```

2. **Buat Config Baru**
   Misalnya:

   ```bash
   sudo nano /etc/supervisor/conf.d/marimoi-worker.conf
   ```

   Isinya:

   ```
   [program:marimoi-worker]
   process_name=%(program_name)s_%(process_num)02d
   command=php /var/www/marimoi/artisan queue:work --tries=3 --sleep=3 --timeout=90
   autostart=true
   autorestart=true
   user=www-data
   numprocs=1
   redirect_stderr=true
   stdout_logfile=/var/www/marimoi/storage/logs/worker.log
   stopwaitsecs=3600
   ```

   ⚠️ Ganti `/var/www/marimoi` sesuai path project Laravel Anda.

3. **Reload Supervisor & Jalankan**

   ```bash
   sudo supervisorctl reread
   sudo supervisorctl update
   sudo supervisorctl start marimoi-worker:*
   ```

4. **Cek Status**

   ```bash
   sudo supervisorctl status marimoi-worker:*
   ```

5. **Cek Log Queue Worker**

   ```bash
   tail -f /var/www/marimoi/storage/logs/worker.log
   ```

---

### ✅ 3. Tips Tambahan

* Gunakan `--sleep=3` agar worker istirahat sebentar kalau tidak ada job.
* Gunakan `--timeout=90` agar job panjang tidak otomatis dihentikan terlalu cepat.
* Di production, selalu pakai `queue:work` (bukan `queue:listen`, karena lebih efisien).
